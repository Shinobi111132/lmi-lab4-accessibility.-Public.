# Лабораторна робота № 4 — Покращення доступності вебсторінок

Предмет: «Людино-машинний інтерфейс».

Вихідний навчальний проєкт: https://gitlab.com/kipz_tov/a11y-practical-task/-/tree/main

У роботі збережено оригінальний сайт ACME Fashion House та його ресурси.

## Що змінено

- **main.html**: уточнено заголовок вкладки, мову сторінки `en-GB`, посилання пропуску навігації, ієрархію заголовків та семантичні області; виправлено порядок переходів Tab, контрастність, альтернативні описи зображень, назви посилань та списки у футері.
- **form.html**: поля мають пов'язані мітки, потрібні поля стали обов'язковими, а параметри доставки згруповано у `fieldset` з `legend`.
- **assets/css/site.css**: додано оформлення пропуску навігації, помітний фокус та кольори з кращим контрастом.

## Перевірка

Локально перевірено структуру HTML, наявність потрібних атрибутів і поведінку обов'язкових полів у браузері. Повна перевірка axe/WAVE та озвучення через NVDA або VoiceOver окремо не підтверджені.

Щоб переглянути сторінки, скачайте репозиторій як ZIP, розпакуйте його й відкрийте `main.html` або `form.html` у браузері. Папку `assets` залиште поруч із HTML.
